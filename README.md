# react-tablero-tareas

Tablero de tareas en React: hook propio (useTasks), estado derivado y render de listas.

> Proyecto de portafolio de Luis Felipe Zuniga Leon. Desarrollado con asistencia de IA
> (generacion de codigo, revision y documentacion); el codigo fue revisado y probado manualmente.
> No declara clientes, metricas ni resultados no verificables.

## Stack

- React 18
- Vite
- Vitest

## Como ejecutar

```bash
npm install
npm run dev
npm test
```

## Estructura

```
src/App.jsx        # componente principal
src/useTasks.js    # logica de estado (hook)
src/main.jsx       # montaje
src/styles.css
```
